# 峡谷争锋 v4

一个原创的、可在浏览器运行的 3D MOBA 原型。借鉴 5v5、三路兵线、野区、防御塔和水晶等常见 MOBA 机制；不使用《王者荣耀》的官方角色模型、图像、音效或商标素材。

## 当前包含

- 5 名原创英雄：曜铠、逐风、星澜、影刃、青禾，各有不同属性与三项技能。
- 3 条兵线、中央河道与桥梁、林地装饰、双方基地。
- 5v5 英雄阵容、AI 推线与交战、兵线刷新、野怪营地。
- 每路 3 座防御塔、双方水晶、核心保护机制与胜负结算。
- 英雄等级、经验、金币、装备商店、回城、恢复、闪现、复活。
- 键盘、鼠标、触屏摇杆和技能按钮。
- 本地 Three.js 运行时，无需外部 API 或云端生成服务。

## 操作

| 操作 | 控制 |
|---|---|
| 移动 | WASD / 方向键 / 点击地面 / 触屏摇杆 |
| 普通攻击 | 空格 / J / 普攻按钮 |
| 技能 | Q、E、R / 技能按钮 |
| 装备商店 | B / 装备按钮 |
| 恢复 | D / 恢复按钮 |
| 闪现 | F / 闪现按钮 |
| 暂停 | Esc / 暂停按钮 |
| 回城 | 回城按钮 |

建议使用桌面浏览器，或将手机横屏游玩。

## 目前的边界

这是可玩的原型，不是商业级完整复刻。英雄使用程序化低多边形模型，AI 与寻路采用简化逻辑，技能数值尚未进行充分平衡测试；目前没有完整音效、排位、联网对战、账号系统或正式美术资产管线。下一轮应优先修复玩法漏洞、验证长时间对局、改善角色动画和地图视觉，而不是继续堆砌菜单。

Three.js 运行时的许可证见 LICENSE-three.txt。
