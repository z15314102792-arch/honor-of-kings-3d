# 王者荣耀 · 高还原复刻实验版 v5

这是对《王者荣耀》可观察游戏体验进行高还原复现的非官方浏览器实验，不是另创一款 MOBA。没有打包官方客户端代码、模型、贴图或音效。

## 当前实现
- 以亚瑟、后羿、妲己、李白、瑶为可选英雄，使用不同轮廓、武器、特效和技能逻辑。
- 5v5、三路推进、河道与野区、兵线、防御塔、水晶、经济、装备、复活、回城、恢复、闪现。
- 三路与河道改为对角布局，加入更细的地表、林地、桥梁、基地、塔体和小兵模型。
- 桌面键盘/鼠标与手机横屏摇杆/技能按钮。
- 启动异常会在页面显示错误，不再静默卡在主界面。

## 操作
- 移动：WASD / 方向键 / 点击地面 / 触屏摇杆
- 普攻：空格 / J / 普攻按钮
- 技能：Q / E / R
- 装备：B / 装备按钮
- 恢复：D；闪现：F；暂停：Esc
- 回城：回城按钮

## 真实边界
当前仍是高还原方向的可玩原型，不等同于官方客户端：没有官方高模、完整骨骼动画、全部英雄技能机制、排位/匹配、网络同步或服务端。下一步按真实对局验收逐项补齐，而不是添加无关原创系统。
