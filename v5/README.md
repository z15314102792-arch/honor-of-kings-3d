# 王者荣耀复刻实验版 v5

这是一个浏览器内可运行的非官方复刻实验，目标是按《王者荣耀》的大厅、选将和 5V5 对局结构逐步还原，不是原创 MOBA。未打包官方客户端代码、模型、贴图或音效。

## 进入游戏
1. 打开网页后，点击底部右侧 **开始游戏**。
2. 选择 **王者峡谷 5V5**，点击 **进入英雄选择**。
3. 选择英雄，点击 **确认选择并开始**。
4. 等待加载界面结束，进入本地 5V5 人机对局。

也可以从大厅点击“查看英雄”先浏览英雄，再返回大厅开始游戏。

## 当前实现
- 大厅：顶部账号与货币信息、左侧导航、3D 英雄展示、右侧模式入口、底部开始游戏按钮。
- 流程：大厅 → 模式选择 → 英雄选择 → 加载 → 对局 → 胜负结算。
- 英雄：亚瑟、后羿、妲己、李白、瑶；各自有独立的程序化模型、武器和技能效果。
- 对局：三路、河道与野区、兵线、防御塔、水晶、AI 英雄、经济、装备、回城、恢复、闪现和复活。
- 操作：桌面键盘/鼠标；手机横屏摇杆和技能按钮。
- 启动异常会在页面显示错误信息。

## 操作
- 移动：WASD / 方向键 / 点击地面 / 触屏摇杆
- 普攻：空格 / J / 普攻按钮
- 技能：Q / E / R
- 装备：B / 装备按钮
- 恢复：D；闪现：F；暂停：Esc
- 回城：回城按钮

## 当前边界
这是可玩的复刻原型，不等同于官方客户端。当前没有官方高模、完整骨骼动画、全英雄技能、排位系统、在线匹配或网络同步；排位赛与独立训练营入口会明确提示尚未接入。后续应优先提升角色模型、动画、UI 和对局规则的还原度。
